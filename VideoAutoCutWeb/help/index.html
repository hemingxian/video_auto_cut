01

准备工作

开始之前

从官网下载安装包并完成安装。启动 VideoAutoCut Studio 后，先登录已有账号； 没有账号时可以在登录窗口直接注册。

稳定的网络 脚本解析、素材下载、语音和画面理解需要访问在线服务。
足够的磁盘空间 原素材、候选片段、音频和最终视频会保存在工作目录中。
可用的脚本 可以是文档、表格、纯文本、字幕或结构化 JSON。
第一次启动

软件可能需要准备视频生成运行环境。保持软件开启，等待准备完成后再开始任务。

02

最快路径

快速生成第一条视频

  1. 1
    添加脚本

    进入“开始任务”，点击右上角的“脚本文件”，选择一个脚本后点击“完成”。

  2. 2
    选择素材方式

    点击“素材设置”。需要软件搜索素材时选择“下载新素材”；已有视频已经放入素材库时选择“使用已有素材”。

  3. 3
    先检查分镜

    点击“预览分镜”，等待脚本解析完成。打开“编辑分镜”检查口播、搜索词、画面和剪辑要求，修改后点击“保存”。

  4. 4
    生成并查看结果

    点击“生成视频”。在“当前流程”查看处理步骤，完成后点击“播放成片”，也可以到“历史任务”中再次查看。

推荐先预览分镜

软件也支持直接生成，但先检查分镜更容易提前发现口播文案、搜索词或画面要求不准确的问题。

03

输入内容

脚本如何准备

软件可以理解没有固定表头的文档，但如果已经准备了分镜，建议按“一个分镜一组内容”的方式编写。 每个分镜至少写清楚分镜标题、时长、口播文案和画面内容；素材搜索词和剪辑要求可以按需补充。 这种写法更容易稳定解析，也方便生成前逐项检查。

Excel Word PDF TXT / Markdown CSV / JSON SRT
完整分镜脚本示例 推荐格式，可直接复制修改 
视频标题：AI 如何改变视频制作流程
预计时长：约 40 秒

分镜 1｜传统制作流程
时长：0-8 秒
口播文案：
过去制作一条完整视频，需要依次完成写稿、寻找素材、配音、字幕和剪辑。
画面内容：
夜晚的办公室里，视频编辑人员面对多块屏幕工作，屏幕上显示剪辑时间线。
素材搜索词：
video editor working late timeline
剪辑要求：
从编辑人员工作画面切到时间线特写，节奏稍快，突出步骤繁琐。

分镜 2｜AI 整理分镜
时长：8-18 秒
口播文案：
现在，AI 可以先理解脚本，把内容整理成清晰的分镜，并为每一段生成画面要求。
画面内容：
电脑屏幕上依次出现脚本文档、分镜列表和结构化的任务流程。
素材搜索词：
AI video workflow script storyboard
剪辑要求：
使用平滑推近镜头，重点展示脚本变成分镜列表的过程。

分镜 3｜搜索和匹配素材
时长：18-29 秒
口播文案：
系统会根据分镜搜索候选素材，再通过画面理解找到与文案语义匹配的片段。
画面内容：
素材缩略图快速排列，搜索结果被逐个筛选，最终选中的视频出现高亮。
素材搜索词：
video asset search media library
剪辑要求：
先展示多个候选素材，再聚焦到最终选中的画面；字幕保持清晰可读。

分镜 4｜输出成片
时长：29-40 秒
口播文案：
创作者仍然决定内容和表达，工具负责减少重复操作，让更多时间回到创作本身。
画面内容：
创作者检查最终视频，点击播放后露出满意的表情，最后停留在完成的成片画面。
素材搜索词：
content creator reviewing finished video
剪辑要求：
节奏逐渐放缓，结尾淡出；最后显示文字“把时间留给创作”。

字段名称不要求与示例完全一致，但口播文案、画面内容和剪辑要求不要混在同一句中。 字幕样式、进度条等统一画面设置请在软件“设置”页面配置，不要写进脚本示例。 需要同时处理多个脚本时，可以在“脚本文件”窗口继续点击“添加脚本”，软件会把它们加入任务队列并按顺序处理。

04

素材范围

选择素材模式

模式 A

下载新素材

软件根据每个分镜的搜索词，从所选素材来源搜索并下载候选视频，再选择合适片段。

  • 适合还没有准备视频素材的任务
  • 可以选择默认来源、Pexels、Pixabay 或 Wikimedia Commons
  • 素材来源选项只在这个模式下生效
模式 B

使用已有素材

软件从素材库和已有的语义索引中寻找与分镜画面要求相符的视频片段。

  • 适合使用企业、自有或已经下载的固定素材
  • 开始任务前先在“素材库”中添加视频
  • 不需要再选择外部素材来源
素材授权

使用下载素材前，请根据实际发布场景确认素材平台的许可证、署名和使用限制。

05

生成前检查

预览和编辑分镜

点击“预览分镜”后，软件只整理脚本并建立分镜，不会直接开始最终视频生成。 分镜准备完成后，“分镜工作区”会显示每段内容及其素材状态。

分镜标题帮助快速识别这一段在视频中的作用。
口播文案这一段最终用于配音和字幕的文字。
素材搜索词下载新素材时用于搜索，建议简短、具体。
想要的画面描述主体、场景、动作、镜头或画面风格。
剪辑要求补充节奏、动画、卡片或其他剪辑要求。
修改后记得保存

“编辑分镜”顶部出现“未保存”时，点击“保存”后再生成视频。

06

处理过程

生成视频与查看进度

点击“生成视频”后，任务会进入队列。“当前流程”显示正在执行的阶段、整体进度和失败位置； “分镜工作区”按分镜显示候选片段和已经剪辑的片段。

读取脚本 整理分镜 搜索素材 剪辑片段 配音字幕 合成成片
任务队列

查看等待中和执行中的任务，也可以停止当前任务。

查看日志

显示正在执行的具体命令、警告和失败原因。

目录

打开当前任务文件夹，查看脚本、音频、字幕、片段和输出文件。

播放成片

任务完成后使用系统播放器打开最终视频。

07

视频资源

使用素材库

素材库用于保存和整理原始视频。点击“添加素材”导入视频，使用“新建文件夹”整理内容； 点击文件夹进入，点击视频可以直接预览。

文件夹搜索

输入文件夹名称，快速找到已经整理好的素材分类。

语义搜索

用自然语言描述画面，例如“工业机器人在工厂里工作”。

右键菜单

在视频或文件夹上点击右键，可以重命名、删除或查看可用操作。

素材目录

在 Windows 文件资源管理器中打开软件管理的素材位置。

语义搜索没有结果时

先确认视频已经成功导入，再换成更具体的画面描述重新搜索。

08

结果管理

查看历史任务

“历史任务”保留已经建立的任务目录。先在左侧选择任务，再在右侧查看输出文件。 已生成最终视频的任务会显示“已完成”标识。

  • 播放视频：打开当前任务的最终成片。
  • 目录：打开任务在 Windows 中的保存位置。
  • 查看日志：检查生成过程、警告和失败原因。
  • 任务文件：查看或删除任务产生的视频、音频、字幕、图片和数据文件。
09

声音设置

克隆和使用音色

  1. 1

    在“音色克隆”中点击“添加音频”，选择 MP3、WAV 或 M4A 声音样本。

  2. 2

    选择声音模板，填写只包含英文字母和数字的音色前缀。

  3. 3

    点击“创建音色”，等待处理完成。

  4. 4

    在“已克隆音色”中选择并应用需要使用的音色。

请只使用有权使用的声音

克隆他人声音前应获得明确授权，不要用于冒充、欺骗或未经允许的内容发布。

11

遇到问题

常见问题

“预览分镜”按钮为什么不能点击？

先点击“脚本文件”并至少添加一个脚本。脚本路径有效后，预览分镜按钮才会启用。

为什么素材搜索不到或画面不合适？

打开“编辑分镜”，把“素材搜索词”改得更短、更具体，并在“想要的画面”中补充主体、场景和动作。使用已有素材模式时，也要先确认视频已经导入素材库。

任务失败后应该先看哪里？

先在“当前流程”确认失败阶段，再点击“查看日志”阅读最后一段错误。历史任务中也可以重新打开任务日志和对应目录。

生成过程中可以关闭软件吗？

不建议。视频生成引擎正在下载、分析或渲染时，请保持软件运行，等待任务成功或明确停止任务。

软件更新一直停在处理中怎么办？

先保持网络连接并等待当前下载或安装阶段结束。长时间没有变化时，重新启动软件后到“设置 → 关于与更新”再次检查。

如何找到生成的视频和中间文件？

在“开始任务”或“历史任务”中选择对应任务，然后点击“目录”。最终视频、日志以及任务产生的中间文件都保存在该任务目录中。

仍然无法解决？ 反馈时请附上失败阶段和日志末尾内容。
