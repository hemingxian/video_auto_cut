# 修改分镜后局部续跑：实现与验证记录

日期：2026-09-15。对应飞书第 16 条。本记录描述工作区代码与隔离测试，不代表已发布或已通过真实云模型成片验收。

## 行为

新生成任务会写入 `incremental.json`（`schema_version: 1`）。以稳定的 `shot_id` 为单位记录每阶段的输入摘要和产物 SHA-256。继续任务时，输入相同且产物存在、非空、内容摘要一致，才能复用；仅有文件名或整个任务的“已完成”标记不作为依据。

| 修改或缺失 | 重新执行 | 保留 |
| --- | --- | --- |
| 仅编辑显示字幕 | 最终字幕渲染、合成 | 检索词、素材、配音、剪辑片段 |
| 修改口播、音色、语音模型或采样配置 | 对应分镜配音、字幕时间线、最终合成 | 其他分镜配音和有效素材、剪辑 |
| 修改画面描述或剪辑要求 | 对应分镜检索词优化及剪辑；优化后下载词确实改变时重新准备其下载素材 | 无关分镜 |
| 修改素材绑定范围 | 该分镜的素材准备、剪辑、最终合成 | 无关分镜及旧范围产物 |
| 调整分镜顺序、标题 | 时间线、音频序号映射、当前剪辑清单、最终合成 | 按 `shot_id` 保存的素材、配音及剪辑 |
| 素材准备产物丢失或内容损坏 | 对应分镜素材准备 | 其他分镜产物 |
| 剪辑产物丢失，但素材和索引仍有效 | 对应分镜索引检查及搜索剪辑 | 已有素材、有效索引和其他分镜 |
| 索引缺失，但该分镜有效剪辑已存在 | 直接复用剪辑 | 不为合成重新调用索引模型 |
| 仅当前序号的配音投影文件缺失 | 从经过校验的分镜配音缓存恢复序号文件 | 不重新请求语音模型 |
| 分镜配音缓存实际丢失 | 对应分镜配音 | 有效的视觉结果 |
| 仅最终成片缺失 | 最终合成 | 有效的上游分镜产物 |

“最终合成”目前仍会完整渲染当前片段并生成整片；没有声称只重渲染最终视频中的一个片段。局部复用覆盖耗时的素材检索、准备、索引/剪辑和配音步骤。

## 边界与数据一致性

- 新的不同素材范围使用不同的任务内目录，不混入旧范围的候选文件。旧文件保留，但素材库登记和工作台只读取当前素材回执、当前严格版本的 `clip_manifest.json`，不把历史目录重新扫进候选数量。
- 工作台候选与剪辑采用产物携带的 `shotId` 归属；旧任务仍兼容目录编号解析。顺序调整不会把旧编号目录的片段显示到另一分镜。
- 当前版本的剪辑清单仍校验任务版本和运行目录。复用时由经过校验的分镜回执重建清单，不放宽旧版本清单的校验。
- 剪辑回执保留生产者返回的排名顺序，不按文件名字典序重排。
- 文件摘要不一致时，在当前任务目录内隔离损坏文件，再交给对应阶段重建；不移动任务外的源文件。
- `素材匹配最低分`、排除字幕/Logo/水印、指定范围随机兜底以及视觉审核/嵌入模型均计入剪辑输入。两个剪辑策略开关的变化不使下载阶段失效。
- `DASHSCOPE_TTS_*` 的音色、模板、模型、音频格式和采样率等设置计入配音输入；只变更这些设置不会重新检索或剪辑素材。密钥、令牌不写入摘要配置。
- 最终渲染摘要包含当前分镜完整内容、模板包装版本 1、包装开关、字幕安全区开关、模型与服务地址等渲染相关配置。
- 前端编辑字幕和口播时保留素材绑定；只有画面检索相关字段变更才取消旧自动解析。素材解析仅针对素材字段改变或缺乏基准记录的分镜；模式变化则重新解析全部分镜。
- 重新冻结素材清单由主进程校验原素材身份、版本、暂存文件 SHA-256、当前任务和素材模式。未改变绑定且暂存有效的分镜可以使用暂存路径，即使原始源路径已不存在；修改画面描述但绑定不变也遵循此规则。云端仍校验当前账号权限并冻结新运行，返回成员必须与复用的冻结记录严格一致，不能用暂存记录绕过权限或版本校验。
- 未带逐分镜回执的旧任务只能按原检查点继续未修改输入。修改旧任务需要“重新生成全部”一次；不会伪造可复用证明。

## 已完成隔离验证

- Rust 增量模块 6 项通过：阶段依赖、实际语音配置、损坏/缺失/越界产物、顺序变更后的清单版本和排名、顺序变更后的语音映射、单独改变素材范围。
- 素材范围测试先准备 A/B，再只改变 A，并删除 B 的原始源文件；引擎仍使用已校验的 B 暂存文件，A 不混入旧候选。测试不使用下载器或模型执行器。
- 顺序与配音复用测试把执行器设为不可执行路径，确保不会悄悄重新调用检索、剪辑或 TTS。
- 桌面当前产物清单及素材登记测试验证：仅登记有效回执内原素材，排除旧项目目录、旧范围目录、索引副本、已删除分镜及越界文件；按稳定 ID 映射重排后的分镜。
- Windows 实机检查覆盖 Rust 回执中的 `\\?\` 长路径：Node 24 的普通 `realpathSync` 可抛出 `EISDIR / lstat D:`，产物读取已改用原生路径解析，并在回归中使用带此前缀的真实临时文件及运行目录。
- 相应桌面素材服务与当前产物测试 30 项通过；前端任务模型 39 项通过，包含仅文字编辑不重新解析素材、只解析变更子集、模式变化全部解析。
- Electron、渲染端 TypeScript 检查通过。
- 桌面续跑清单 8 项隔离测试通过：本地和云服务模拟中的原源丢失复用、视觉描述变更保持相同绑定、模式/版本/任务边界、Windows 长路径、损坏/越界缓存、权限或冻结版本不匹配、云校验期间文件变更、大于 100 个成员的范围及重复成员拒绝。与当前产物测试合跑 9/9 通过。

## 仍需真实验收

上述验证没有使用真实账号上传或调用在线模型，不等同于真实端到端成片。真实云模型验收当前由主任务处理登录状态后继续；需在同一任务中分别修改字幕、口播、画面描述及素材范围，检查实际调用记录、成片声音/字幕与镜头一致性，并验证暂停恢复和最终成片缺失恢复。

前端重建清单曾因未修改分镜的原素材路径失效而阻断续跑；该链路已修复，并完成上述桌面与引擎隔离回归。真实云账号下的整条流程仍属于后续端到端验收范围。
