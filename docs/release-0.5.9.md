# 0.5.9 发布验收

桌面端和视频生成运行环境均已发布 0.5.9，候选安装包、运行包解包复测和公开下载校验通过。

## 本次修复

- 同一素材按内容 SHA-256、编码配置及分析参数复用转码和向量结果。多个分镜、连续任务不再因为文件路径变化重复处理同一素材。
- 每个分镜仍只在自己的素材范围内独立检索、排序、按最低分选片；74 个候选表示可供检索的素材数，不是要使用 74 段视频。
- 默认预处理从经过校验的原文件读取，同一原素材、规范化副本和兼容的云端分析能够共享结果。旧结果缺少完整分析参数时，需先建立一次可验证索引。
- 索引日志显示文件、分块、缓存命中、阶段和耗时，并实时写入 run.log。FFmpeg、模型上传/推理及索引进程均有明确时限，超时会清理子进程树。
- 缓存逐块保存，失败或暂停后继续可复用已完成块。源文件、参数变化或缓存损坏时重建受影响结果；失败不会留下虚假的“已完成”记录。
- 云端增加可选分析参数凭据，绑定素材内容并校验分页与配置一致性，旧客户端仍可使用原接口。
- 运行包明确排除素材、向量数据库、分析缓存、转码缓存及登录配置。

同时包含本轮已验证的飞书反馈修复：历史任务恢复与分镜局部重试、素材页缓存、分析同步错误区分、输出分辨率、字体和完整字幕布局。可选画面审核、字幕避让及模板包装默认关闭；未完成真实案例验收的反馈保持未解决。详见 [反馈修复记录](feishu-remediation-2026-09-15.md)。

## 发布前验证

- 桌面回归：323 通过、2 项既有跳过；渲染器、Electron、预加载和发布脚本构建通过。
- Python：211 通过、2 项环境跳过；使用内置 Python 另跑 13 项全部通过，覆盖实际 Chroma 和导入/导出命令，补齐两项跳过。
- Rust：109 通过、4 项标记忽略；显式运行其中 2 项真实 FFmpeg 缓存测试全部通过。其余两项原有忽略保持原状。
- 服务端：60 项通过。实际 PostgreSQL 临时表执行真实仓库方法，验证迁移、分页、向量和凭据往返、身份及配置冲突；事务已回滚，没有写业务数据。
- 真实 Qwen、FFmpeg、引擎后台测试：3 份实际工厂视频、3 个独立分镜、连续 2 个任务，生成两份 1280×720、6.021 秒成片，全帧解码无错误。首镜 3 次分析，后续分镜及第二任务 0 次新增分析；不同检索词选出不同素材，单素材范围没有越界。

上述短素材测试验证此次复用链路，不代表完整业务脚本的画面语义验收，也不以小样本耗时承诺 74 份首次分析的固定时长。

- 引擎 ZIP 的 18,715 个文件通过路径检查，170 项第一方源文件及正式引擎摘要一致；未混入凭证、用户数据库、素材或缓存。内置 Python、FFmpeg 实际编码、字体及 1 秒透明模板真实渲染通过。
