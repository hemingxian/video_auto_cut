# 素材库 UI 设计规范

版本：2.0
视觉基准：用户提供的图二
基准画布：1680 × 945 px

## 1. 页面骨架

| 区域 | 基准位置与尺寸 |
| --- | --- |
| 应用外边距 | 左/上 6 px，右 12 px，下 10 px |
| 功能侧栏 | `90 × 930 px`，圆角 18 px |
| 主内容框 | `1558 × 930 px`，左侧起点 110 px，圆角 18 px |
| 页面标题 | 左 147 px，上 47 px，28 px / 700 |
| 顶部操作按钮 | 高 50 px，间距 12 px |
| 搜索与筛选栏 | `x=135, y=108, 1503 × 44 px` |
| 素材工作区 | `x=135, y=176, 1503 × 723 px` |

素材工作区是三个相互独立的面板，不使用一个大外框包裹：

| 面板 | 宽度 | 间距 |
| --- | ---: | ---: |
| 素材文件夹 | 250 px | 8 px |
| 素材内容 | 847 px | 8 px |
| 素材详情 | 390 px | — |

三个面板均使用 1 px `#303B49` 描边、9 px 圆角和深蓝黑渐变背景。

## 2. 顶部工具区

搜索区与筛选区必须位于同一行。

- 搜索类型：142 × 44 px。
- 搜索框：487 × 44 px。
- 搜索按钮：76 × 44 px。
- 搜索控件间距：12 px。
- 筛选标签组：连续分段按钮，不使用分散的文字标签。
- 单个标签高 42 px，激活项高 44 px。
- 视图切换器：两个 54 × 32 px 图标按钮，外框高 44 px。

顶部操作按钮固定高度 50 px。基准宽度分别为：

- 刷新：112 px。
- 素材目录：146 px。
- 新建文件夹：165 px。
- 添加素材：159 px。

## 3. 文件夹面板

- 标题栏高 54 px，标题为“素材文件夹”，右侧为新建文件夹按钮。
- 文件夹行高 45 px。
- 图标 21 px，正文 16 px，数量 14 px。
- 选中项使用蓝色渐变背景和蓝色图标，不使用黄色文件夹。
- 面板只展示文件夹导航，不展示磁盘空间进度。

## 4. 素材卡片

基准卡片尺寸为 `201 × 276 px`，四列布局：

- 第一行卡片起点：`x=400, y=265`。
- 横向间距：10 px。
- 纵向间距：12 px。
- 卡片圆角：7 px。
- 默认描边：`#34404F`。
- 选中描边：`#1780FF`，追加轻微蓝色外圈。

缩略图要求：

- 卡片内边距 7 px。
- 基准尺寸约 `185 × 182 px`。
- 圆角 5 px。
- 视频可用时显示真实视频帧。
- 视频帧未就绪时显示工业场景占位图，禁止使用抽象渐变块。
- 时长标签固定在右下角。
- 勾选框固定在缩略图左上角，24 × 24 px。

卡片标题使用 15 px / 570，单行省略。状态标签使用 13 px，按实际状态组合展示。

## 5. 素材内容区

- 内容标题区高 80 px。
- 第一行显示面包屑。
- 第二行显示当前目录素材数量。
- 素材网格内边距为上下 8 px、左右 6 px。
- 底部分页区高 58 px。

选择素材后，批量操作条固定在内容区右上：

- 位置：`x=715, y=186`。
- 尺寸：`512 × 48 px`。
- 蓝色描边 1 px，圆角 7 px。
- 操作顺序：移动、上传云端、删除、关闭。

批量操作条不得覆盖文件夹栏和详情栏。

## 6. 详情面板

- 标题栏高 54 px，标题为“素材详情”。
- 内容左右内边距 18 px。
- 预览区基准尺寸约 `352 × 251 px`。
- 预览区带进度条、播放、时间、音量和全屏控制。
- 文件名使用 19 px / 620。
- 状态标签依次为分析状态、存储状态、可见范围。
- 属性行高 43 px，只展示时长、分辨率、大小、所在文件夹。
- 底部操作按钮高 54 px，分别为“打开视频”和“更多操作”。

本地文件路径和 URL 不得在页面中显示。

## 7. 色彩

| Token | 色值 |
| --- | --- |
| 页面背景 | `#0B121A` |
| 面板背景 | `#101923` |
| 深层背景 | `#0B1119` |
| 控件背景 | `#141D28` |
| 默认描边 | `#303B49` |
| 强描边 | `#435063` |
| 主文字 | `#F1F5F9` |
| 次文字 | `#C1CAD6` |
| 弱文字 | `#7D899A` |
| 主色 | `#1478FF` |
| 危险色 | `#FF686B` |

状态色：

- 已分析：`#65C87D`。
- 分析中：`#F2B53C`。
- 同步失败：`#FF6C6A`。
- 本地和云端：`#4C9BFF`。

## 8. 响应式

| 页面宽度 | 规则 |
| --- | --- |
| `> 1480 px` | 使用完整三栏与四列卡片 |
| `1261–1480 px` | 三栏收窄，卡片等比压缩 |
| `981–1260 px` | 隐藏详情栏，卡片三列 |
| `≤ 980 px` | 侧栏回退到 64 px，隐藏文件夹栏，卡片两列 |

## 9. 数据规则

正式数据优先显示真实视频帧。状态字段仍由接口提供：

- `storage_state`：`local / cloud / both / sync_failed`
- `analysis_state`：`ready / processing / failed / pending`
- `visibility`：`private / public`
- `duration_ms`
- `width`
- `height`
- `folder_name`
- `thumbnail_url`

示例页中的工业缩略图只用于设计验收和视频帧加载前的占位，不替代真实素材数据。
