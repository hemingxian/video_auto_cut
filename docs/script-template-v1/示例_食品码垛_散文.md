# 箱装食品码垛工作站 宣传片脚本（客户稿）

做一条 80 秒左右的横屏宣传片，讲箱装食品是怎么码上托盘的。全片男声配音，语速稍快，下面每段引号里的话就是配音原文，一个字不要改。不要出现任何客户和设备厂商的名字。

开头先交代场景：食品包装线的最后一段，好几台橙色码垛机器人同时在干活，输送线和托盘位都在画面里。配音：“食品包装线的末端，一箱箱成品下线以后，最重复、最累人的一道活，就是码垛。”

接着看来料。整箱的瓶装水在输送带上排着队往前走，一箱一箱送到机器人能抓的位置。配音：“整箱的瓶装水、纸箱装的牛奶，装好箱以后先在输送带上排好队，一箱一箱送到机器人的抓取位。”

然后是抓取。红色机械臂从输送带上抓起一箱牛奶，抬起来、转过身，送到托盘上方。这一段用特写，让人看清楚抓起和转身的动作。配音：“机器人从输送带上抓起整箱，抬起、转身，送到托盘上方。抓得稳、转得快，节拍才跟得上产线。”

再看落位。机械臂把纸箱放到红色托盘上，托盘上已经码好了好几层。
上屏：一层码满，再码下一层
配音：“落到托盘上，每一箱的位置和朝向，都按设定好的垛型来，一层码满，再码下一层。”

码齐以后看整垛：托盘上好几层整箱整整齐齐，机械臂还在继续往上码。配音：“箱子码得整齐，整垛才稳。后面叉车转运、进库存放，都不容易倒箱、塌垛。”

讲一下换箱型。瓶装水车间里好几条输送带并排，机械臂在输送带和托盘之间来回搬整箱。配音：“同一个工作站，箱型变了，改的主要是垛型程序，必要时再换抓具，不用动整条线。”

人和机器的分工：工人在码垛工位旁边巡视，身后机器人一直在码箱子。配音：“现场留一个人巡线、换托盘就够了，搬箱子这种重复的体力活，交给机器人。”

然后讲选型要准备什么，画面还是机械臂码瓶装水。配音：“想上一套码垛工作站，先把这四样准备好：箱子的尺寸和重量、每小时要码多少箱、托盘规格，还有目标垛型。”

最后收尾，码满的红色托盘停在工位旁，机器人开始下一轮。配音：“把你的箱型和垛型发过来，我们照着现场条件，帮你把这一段码垛工位排出来。”
