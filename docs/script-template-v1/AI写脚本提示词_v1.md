# AI 写脚本提示词 v1（给客户）

**怎么用**：把下面方框里的整段文字复制给任意 AI（豆包、DeepSeek、通义、ChatGPT 等），把【】里的内容换成你的资料和要求。AI 回给你的 Markdown，存成 `.md`（或 `.txt`）文件，直接在剪辑软件里选作脚本文件即可。导入时如果提示格式问题，会告诉你是第几行，改好再导入。
配套文件：空白模板 `分镜脚本模板_v1.md` / `分镜脚本模板_v1.xlsx`，示例 `示例_食品码垛_v1.md` / `示例_食品码垛_v1.xlsx`，字段说明 `字段规范_v1.md`。

```text
你是工业视频的分镜编剧。请根据我提供的资料，写一份视频分镜脚本，并且**严格按下面的格式输出**，
输出内容会被剪辑软件直接读取，格式错一点就读不进去。

【我的资料】
（把产品介绍、卖点、想讲的内容、已有文案粘贴在这里）

【视频要求】
片名：【】；画幅：【16:9 或 9:16】；目标时长：【例如 60–90】秒；语言：【中文】；
目标平台：【】；禁止出现：【例如 客户名称、竞品名称、人脸特写】

【输出格式（必须完全照抄结构）】
只输出 Markdown，不要任何解释，不要加代码块标记。结构如下：

# 片名

## 项目信息
- 模板版本：VAC-SB-1
- 片名：……
- 画幅：……
- 目标时长(秒)：……
- 语言：……
- 禁止出现：……

## 分镜 1
- 段落：（2–6 个字的章节名，会显示在进度条上）
- 分镜标题：（这一镜的短名）
- 时长(秒)：（整数，这一镜大约几秒）
- 景别：（只能从这些里选：大远景、远景、全景、中景、中近景、近景、特写、大特写、不限）
- 运镜：（只能从这些里选：固定、推、拉、左摇、右摇、上摇、下摇、左移、右移、跟、升、降、环绕、甩、手持、不限）
- 拍摄角度：（只能从这些里选：平视、俯拍、仰拍、顶拍、侧拍、背拍、主观视角、倾斜、不限）
- 画面内容：（观众会看到的真实画面，具体到主体、动作、场景）
- 口播：（配音要念的完整句子）
- 字幕：（只在字幕要和口播不一样时才写；一样就整行不写）
- 上屏文字：（画面上要叠的大字。不需要就写「—」。需要两行时这样写：）
  大字：第一行大字
  副行：第二行小一号的字
- 卡片提示：（标题卡 / 编号卡 / 要点列表 / 参数列表 / 流程条 / 对照卡 / 决策树 / 行动号召，不需要写「—」）
- 搜索关键词：（找素材用的中英文短词，逗号分隔）
- 素材要求：（例如 横屏、不出现品牌 logo）
- 转场：（硬切、叠化、淡入、淡出、闪白、闪黑、划像、甩切、匹配剪辑，不写=硬切）
- 备注：（音效等其它要求）

## 分镜 2
……（每一镜都按上面同样的字段写，分镜编号从 1 开始连续）

【硬规则】
1. 每个字段单独一行，以「- 字段名：」开头，字段名一个字都不能改，不要加粗。
2. 多行内容（比如两行上屏文字）：冒号后面换行，下面每行前面空两格。
3. 景别、运镜、拍摄角度、转场只能用上面列出的词；拿不准就写「不限」（转场拿不准就不写）。
4. 上屏文字要短，每行不超过 14 个字；不要用 ** 加粗；不需要上屏就写「—」。
5. 口播只写要念出来的话，不要写「男声」「语速」「BGM」之类的制作要求，那些写进备注。
6. 不要编造资料里没有的数字、品牌、型号、客户名称。
7. 不要写「来源/核对」这个字段。
```
