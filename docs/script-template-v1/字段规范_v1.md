## 1. 字段

**原则**：字段名、含义、空值规则全部沿用 VAC-SB-1（`模板设计说明.md` §2、9/23 方案 §1.3），**一个字段不改名**；新增只有两处（§1.3），都是为了「AI 整理」这条新路。规范版本号仍叫 **VAC-SB-1**（同一套字段，换载体不换版本）。

### 1.2 占位与空值（三种载体共用，沿用现有函数，不新写一套）

- 占位写法：`-` `—` `——` `/` `／` `无` `没有` `暂无` `空` `留空` `空白` `不填` `不上屏` `N/A` `（不填）` `（无）` → 当空（`script_card_fields.is_placeholder`）。
- 「像占位」的（「没有！」「——（不填）」）→ 不改写，只提醒 `doubtful_value`（`field_doubt`）。
- 景别/运镜/拍摄角度：空、占位、「不限」三者含义相同。存储上：**AI 整理路显式写「不限」**；标准载体（Excel/Markdown）作者留空就不写键，保持 0.5.15 的 xlsx 输出逐字节不变。界面上空和「不限」显示一样（见 §7）。

### 1.3 新增的两处（及理由）

| 新增 | 位置 | 取值 | 理由 |
|---|---|---|---|
| `script_source.route` 新值 `"organized"`；Markdown 标准载体**仍用** `"template"`，另加 `script_source.carrier = "markdown"`（xlsx 不写这个键） | plan 顶层 | `template` / `organized` | md 和 xlsx 是同一规范，用同一个 route，渲染层（`render_segment.py:138`）和桌面端（`shotPlan.ts:162`）对 md 零改动；xlsx 不写 `carrier`，0.5.15 的 xlsx 输出能保持逐字节不变。`organized` 区分「AI 整理」，界面据此显示「AI 整理 · 全部待确认」 |
| `script_meta.field_origin` | 每镜 | `{字段名: "script" \| "ai" \| "default" \| "system"}` | 用户要看到每个字段是脚本原文、AI 整理还是默认「不限」；只在 `organized` 路写（标准载体全是 script，不写，保持 xlsx 逐字节不变） |

其余全部复用：待确认字段仍放 `review.ai_suggested`（界面已按它计数和显示黄条），确认仍放 `review.confirmed`，提醒仍放 `review.warnings`/`acknowledged`，导入快照仍放 `script_values`（「人已改/恢复原文」照旧可用；`organized` 路的「原文」= AI 整理结果）。`schema_version` 仍是 2。

## 2. Markdown 载体

### 2.1 语法（给程序的确定性规则）

1. 文件扩展名 `.md` 或 `.txt`；UTF-8（带不带 BOM 都行）或 GB18030；CRLF/LF 都行。
2. **识别标记**：有一个二级标题 `## 项目信息`，其下有一行 `- 模板版本：VAC-SB-1`。没有这行 = 不是标准 Markdown，走 AI 整理路（与 xlsx 规则一致）；有标记但版本不对、或结构错 → **阻断**，不退回 AI。
3. 第一个一级标题 `# …` 是片名的展示用（可省；以「项目信息 › 片名」为准）。第一个 `## ` 之前的其它内容（说明文字）一律忽略。
4. 每镜一个二级标题：`## 分镜 N`（N 从 1 连续递增）。标题行后面可以跟「｜标题」，但**只做展示**，分镜标题以「- 分镜标题：」为准。
5. 镜内每个字段一行：`- 字段名：值`。字段名必须是 §1.1 的 17 个名字之一（镜号由标题给出，不写「- 镜号」）；全角/半角冒号都认；字段名两边的 `**` 粗体自动去掉（AI 爱加粗）。允许的别名只有一个：`时长（秒）` = `时长(秒)`。
6. **多行值**（上屏文字、来源/核对常用）：冒号后留空，下面每行缩进 2 个空格（或 1 个 Tab）；遇到下一个不缩进的 `- `、下一个 `##` 或空行结束。缩进去掉后逐行保留，行内空白不动。
7. 不写的字段 = 该格为空；一个 `## 分镜 N` 小节里所有字段都为空 = 空行，跳过（与 xlsx 预置空行一致，所以空白模板导入结果 = `no_shots` 阻断）；同一镜同一字段写两次 → 阻断；不认识的字段名 → 进 `extra_columns` + 提醒（同 xlsx 自加列）。
8. 代码围栏 ``` 里的内容一律忽略。
9. **待确认标记**（Markdown 没有底色，用「来源/核对」代替颜色）：
   - 第一行 `校验失败` → 阻断（= 红格）；
   - 有一行 `AI建议：景别、运镜、画面内容`（顿号/逗号分隔字段名）→ 这些字段进 `ai_suggested`（= 黄格）；**其中出现分镜标题/口播/字幕/上屏文字/时长 → 阻断**（= 正文黄格，与 xlsx 同一规则）；
   - 第一行 `待确认` → 提醒；其余说明行 → 提醒 `status_note`。
10. 导入闸门、提醒码、事件格式、`script_meta` 形状**全部与 xlsx 模板相同**；单元格坐标换成行号（`cell` 写「第 23 行」）。

### 2.2 与 xlsx 一一映射

| xlsx | Markdown |
|---|---|
| 「项目信息」sheet 每行 A 列键 / B 列值 | `## 项目信息` 下 `- 键：值` |
| 「分镜脚本」第 1 行 18 个表头 | 字段名（镜号由 `## 分镜 N` 给出） |
| 第 n+1 行 = 第 n 镜 | `## 分镜 n` 小节 |
| 单元格内 Alt+Enter 换行 | 冒号后换行 + 缩进续行 |
| 黄底 | 「来源/核对」里的 `AI建议：…` 行 |
| 红底 | 「来源/核对」第一行 `校验失败` |
| 第 19 列起作者自加列 | 不认识的字段名 |
| 「填写说明」「字典」sheet | 不需要（字典在程序里，与 xlsx 同一份常量） |

**等价要求**：同内容的 xlsx 和 md 导入后的 plan，除 `script_source.file_name / file_sha256 / carrier` 和每镜 `script_meta.source`（sheet+row ↔ carrier+line）外，**深相等**（含 `script_meta.review`、`script_values`、`card_layout`、`render_hints`、`module_label`）。另外两处已知差异不算不等：①提醒/阻断条目里的 `cell`（`R2` ↔ `第 N 行`）；②**xlsx 的 `project_info` 现在会多出一个 `"项目": "填写"`**（`script_template._info` 把「项目信息」sheet 的表头行也当成了键值，`a29d74f` 实测），md 里没有这行。②是 xlsx 导入器的小毛病，本轮**不修**（修了会破坏 N1 逐字节），比较时剔除这个键即可。
