# 0.5.8 发布说明

桌面端更新至 0.5.8，视频生成运行环境继续使用已发布的 0.5.7。本次没有 Rust 引擎、Python 工具或服务端变更。

## 素材范围修复

- 新选择 `scara` 等素材文件夹时，默认包含全部子文件夹；脚本单独绑定、统一绑定及分镜素材选择沿用同一规则。
- 候选数量按生成流程实际展开的绑定范围、资产和版本去重统计，不再直接累加文件夹展示数量。父目录、子目录和其中单个视频重复勾选时，只计算一次。
- 切换“包含子文件夹”后重新统计；统计中、统计失败与空范围分别提示。未完成统计或空范围时阻止确认，旧请求的迟到结果不能覆盖当前选择。
- 只登记和扫描所选范围，同一次统计共享父子目录读取；超过目录遍历上限时明确报错，不展示截断后的数量。
- 修复目录名称含 `_`、`%` 时可能扩大匹配范围的问题，并统一下载目录视图与实际绑定使用的目录编号。
- 未上传下载素材在没有云目录归属时按本地目录展开，已有明确云目录归属的素材不会混入其他云目录。

已有任务保存的 `include_subfolders: false` 保留原义。此前失败的任务需重新选择 `scara`，或勾选“包含子文件夹”后再继续。
