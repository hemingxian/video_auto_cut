# 0.5.7 发布说明

桌面端与视频生成运行环境统一更新至 0.5.7。

## 变更

- 素材来源提供“仅素材库”“素材库 → Pexels”“仅 Pexels”三种模式。素材库范围包含本地及当前账号的云端素材；仅 Pexels 禁止手工绑定范围，仅素材库在缺少可用素材时提示补充。
- 更新模式选择器的图标、选中状态和简短说明，支持键盘操作，移除用户指定的底部说明文字。
- 生成前等待本任务所需素材的登记确认；无需等待整个后台同步队列。保留登记失败的具体原因。
- 修复跨设备同名素材文件夹的编号映射：校验沿用登记成功后的云目录编号，保留各分镜的目录范围和子目录选项，避免登记后仍提示候选为空。
- 素材库减少重复目录扫描，保留已加载页面，先显示本地结果再后台同步，并减少重复云端配置请求。
- 修复“素材匹配最低分”未传入引擎：优先读取 `MATERIAL_MATCH_MIN_SCORE`，兼容 `SENTRY_MATCH_THRESHOLD` 和 `MATCH_ACCEPT_THRESHOLD`，默认值为 0.25。

## 验证范围

桌面端自动化回归 269 项通过、0 失败，另有 2 项原有跳过，含任务登记等待及跨设备目录映射回归。

引擎 82 项单元测试、5 项隔离配置集成测试通过，另有 2 项忽略。配置集成测试使用真实引擎执行 `--shots-json --plan-only`，覆盖 0.1、0.6、配置优先级、旧参数、空值及零值。

从 0.5.7 运行包中提取的引擎与 release 构建哈希一致，另执行 10 次离线配置回归全部通过。运行包文件名检查未发现用户配置、凭据、素材数据库或任务状态。

桌面安装包构建通过；包内版本、三模式界面、已删除文案、素材解析与云同步实现均与本次构建一致，更新清单的文件名和校验值匹配。

## 验证限制

三模式界面使用真实页面、控制器和解析器进行隔离交互验证，外部接口和存储为模拟对象；这不等同于真实素材生成成片的端到端测试。本次发布未重新执行完整成片验收。

阈值修复沿用已有的剪辑判定策略，不改变“自动复用最低分”。旧任务若因修复得到不同的有效配置，原检查点可能需要重新生成全部。
