# 素材库优先：跨设备云端复用验证

日期：2026-09-07。候选桌面版本：0.5.5-rc.8。

## 行为

- 开启“素材库优先”时，先匹配可用本地素材；未达到匹配门槛或本地索引不可用时，再查询当前账号的云端向量。
- 新设备不必先同步整个素材库：为云端命中项补齐素材及文件夹记录，下载合格素材并校验完整性，然后绑定到分镜。
- 无合格素材或下载失败时继续走配置的素材来源（默认 Pexels）。关闭开关时跳过本地和云端素材库。原有手动绑定不变。
- 默认自动复用门槛保持 0.62。
