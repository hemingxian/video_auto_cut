# 0.5.10 发布验收

桌面端 0.5.10 修复同一设备切换账号后的素材身份、任务和后台同步串用问题。服务端同步更新文件夹写入错误分类。视频生成引擎保持 0.5.9，本次没有引擎代码或运行环境变更。

状态：2026-09-15 已完成桌面端发布与服务端部署，正式及 RC 更新清单均指向 0.5.10，公开下载校验通过。

后续发现此版已登录进入工作台会触发界面黑屏，已由 [0.5.11 修复版](release-0.5.11.md) 替代；当前更新清单已升级至 0.5.11。上述记录为 0.5.10 发布当时的验收结果，未覆盖真实窗口启动。

## 修复行为

- 按服务地址和用户 ID 保存独立素材数据库，切换 A→B→A 后恢复各自目录、同步进度和任务记录。
- 切换账号立即终止旧会话的同步和传输，阻止迟到响应、旧任务和旧界面继续向新账号提交。下载文件关闭后再允许新会话使用同一传输路径。
- 内部云端下载缓存不再被当作普通本地素材重新登记；当前账号云素材保留原来的云目录关系。
- 自动备份本地素材开关按账号保存，新账号默认关闭。
- 服务端将账号权限拒绝与同级文件夹重名分开报告，不再把账号归属问题误报为“同级文件夹名称已存在”。保留现有权限与数据库隔离规则。

## 升级与数据保留

旧素材数据库及一致性快照保留，普通本地视频只迁移登记信息，不复制或删除视频。无法确认账号归属的旧云目录 ID、同步队列和任务绑定不会自动转入新账号。首次进入会重新同步当前账号云目录；旧任务若绑定无法确认归属的目录，需要重新选择素材范围。

- 桌面全量测试：354 项，352 通过、2 项原有跳过、0 失败。

- Electron、渲染器、预加载与发布脚本生产构建通过。

- 实际 PostgreSQL 临时表验证旧账号 ID 被 RLS 拒绝、当前账号的新 ID 可正常创建，同账号同级重名触发唯一约束。全部测试写入已回滚。
