# 0.5.12 素材绑定与云备份更新

状态：2026-09-16 已发布。桌面端与引擎均为 0.5.12，正式版与 RC 更新清单一致；配套服务端已部署，公开下载完整校验通过。

## 本次更新

- 素材范围选择减少重复目录扫描和数据库逐项查询，复用目录统计，按当前目录批量读取上传、下载和分析状态。
- 绑定弹窗先展示当前账号的缓存，再刷新；每页显示 24 项，仅加载可见预览，支持跨页勾选。快速切目录和切换搜索词时不再误显示旧结果。
- 素材先在本机完成分析并校验结果，再备份向量和视频。向量确认保存后才上传视频，文件与分析均完成后显示云备份完成。
- 备份待办保存在账号独立的数据库中，关闭应用或切账号会停止本会话处理；重新打开并登录原账号后继续。显式暂停、取消保持不变。
- 服务端返回完整有效的分析结果，视频验证完成不再额外创建待分析记录；分析变化进入增量同步，只有视频与分析都就绪的素材才参与云端检索。
- 口播准备结果保留音频和配套字幕时间轴；续跑复用时校验这组结果，合成使用同一份音频。有口播时字幕使用实际口播文本，避免摘要字幕与音频不对应。

本机分析仍使用现有 Qwen 模型服务，需要网络与有效登录。应用关闭期间不会继续本机分析。

## 升级方式

桌面安装包与引擎运行包均为 0.5.12。覆盖安装即可，不需要先卸载或清空素材。打开后确认视频生成引擎也更新到 0.5.12，再进行生成测试。

已有云文件缺少分析结果时不会被批量标记为已分析；源文件仍在本机的素材可补齐分析与向量，源文件不在本机的会保留实际缺失状态。服务端先部署，客户端随后发布，旧客户端接口保持兼容。
