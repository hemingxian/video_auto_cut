# rc.10 素材目录批量与增量同步

日期：2026-09-07。候选版，尚未稳定发布。

## 行为

- 首次同步按每页 100 条读取目录，按 material_id 去重；详情已完整时不再逐条请求。兼容旧服务端，缺失详情最多 6 路并发补齐。
- 首次快照前取得变化游标，全部素材导入成功后才保存账号及服务地址隔离的同步检查点；后续只请求游标之后的变化，按实体合并重复事件，读取变动素材并处理删除。
- 无变化不重新拉取素材和文件夹；存在素材更新时读取文件夹层级以支持新目录，随后只读取变化素材。
- 失败不前移游标；缺失或无效详情不能静默跳过。批次失败会等待所有已发出请求结束，防止后台遗漏未完成工作。
- 界面显示阶段和已完成/总数，进度事件不触发每条素材的目录重载。
- 服务端分页列表改为带完整内容指纹，部署后能直接批量导入；本次没有部署服务端。当前线上旧接口走兼容并发详情读取。

## 验证

- 桌面测试 223 通过、2 跳过、0 失败；服务端测试 49 通过；桌面完整构建通过。
- 回归覆盖无变化仅 2 次请求、增量更新和删除、失败重试不跳游标、不同账号首次同步、旧接口详情去重及并发上限 6。
- 真实当前账号、独立空数据库、仅允许 GET：首次同步 28,998 毫秒、81 次请求，导入 76 个素材记录；无变化的第二次刷新 1,903 毫秒、2 次请求（配置、变化游标），未读取素材列表或详情。
- 真实结果为本地 0、云端 69、总计 69；左侧、卡片、列表一致。两轮均成功且无待处理或失败队列。耗时为本次测量，随网络和数据量变化。
- 候选运行时复用 rc.7 引擎；本次未进行真实业务视频成片验收，不作为稳定版发布。
