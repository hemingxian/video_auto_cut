# 食品码垛工位要点（全镜上屏）

- 时长：7 秒
- 章节标签：来料到位

- 口播：袋装物料码垛，先看来料怎样到位，再看机械臂如何抓取和落放。
- 字幕：先看来料到位，再看抓取落放
- 上屏文字：来料到位是码垛稳定的第一道关

- 口播：袋料和箱体的外形不同，来料朝向、抓取位置和支撑方式要分别核对。
- 字幕：袋料与箱体分别核对
- 上屏文字：来料朝向、抓取位置、支撑方式，三项分别核对

## 分镜 3

- 时长：8 秒
- 章节标签：节拍与来料
- 画面：袋装物料码垛工位全景，输送带持续来料，机械臂连续抓取
- 口播：这条包装线的设计节拍是每小时七百包，来料不断流，抓取节奏才稳得住。
- 字幕：节拍七百包每小时
- 上屏文字：节拍 700 包/小时｜输送带连续来料｜托盘满垛下线
- 卡片样式：参数卡，列表排版

- 字幕：核对方向与退出路径
- 上屏文字：落盘后先核对方向和边缘，再放行下一层
